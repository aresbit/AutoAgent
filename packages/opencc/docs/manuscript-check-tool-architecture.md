# ManuscriptCheckTool & Nova Agent 架构分析

> 2026-08-03

---

## 一、为什么需要这个工具

Nova 的系统提示里有一份写得很好的"去 AI 味清单"——"不仅…更是…"、"值得注意的是"、
"心中涌起一股暖流"、"与此同时"、"陷入了沉思"、"被…所…"。问题是**这份清单要求模型
自查自己刚写完的散文**，而这些短语恰恰是写的时候觉得最顺手的那些。自查会漏掉大半。

同样的问题贯穿其余硬指标：对话占比 ≥ 30%、每章 ≥ 2 种非视觉感官、"遮住名字也能分辨
是谁在说话"、伏笔"每 5 章审计一次"。这些都不需要品味来判断，只需要数。

工具做机器能做的那部分，把品味留给需要品味的地方。

## 三、`action: "chapter"`

| check | 内容 |
|-------|------|
| `ai_tells` | 9 类模板短语的模式匹配，每处给行号、上下文、为什么是毛病、怎么改 |
| `dialogue_ratio` | 引号内字数占全章比例（默认下限 20%，可调） |
| `sensory_coverage` | 视觉/听觉/触觉/嗅觉/味觉五类词表命中情况，要求 ≥ 2 种非视觉 |
| `length` | 字数区间，不给区间就跳过 |

裁定 `clean` / `needs_revision` / `incomplete`。

工具还会把**开篇和收尾各 200 字原样回显**，并明说：钩子成不成立、情感转折站不站得住，
模式匹配裁定不了，得作者自己读这两段判断。

### 关于 `ai_tells` 的两个实现决定

**翻译腔要锚定在句首。** 最初的规则是 `在[^，。]{2,12}(?:中|下|里)，`，它把
"林砚在灶边蹲下，"也判成翻译腔——那是正常的动补结构。真正的毛病是
"在昏暗的灯光下，"这样**起句**。加上句首锚定后误报消失。

**词表宁可宽一点。** 触觉最初漏掉"冻""烫""发僵"，味觉漏掉"发苦"，结果一段
写满冷热苦辣的散文被判成只有视觉。词表放宽后仍能正确判出纯视觉段落。

## 四、`action: "manuscript"`

### 角色声音辨识度

"遮住名字也能分辨是谁在说话"是 Nova 的第一条黄金规则，听起来最不可量化，其实可以：
**如果两个角色的对话来自同一个用词分布，读者也分不出来。**

- 从各章提取带署名的对话（`角色名说：「…」` 与 `「…」角色名说` 两种语序）
- 中文没有词边界，用**字符二元组**当 token，无需分词依赖
- 计算各角色对话的二元组频率向量，两两算余弦相似度
- 超过 0.86 判失败，并列出各角色的句均长度和特征词

对话不足 120 字的角色列为"样本不足"，报告出来但不参与判定——这比给一个没有意义的
相似度诚实。

### 伏笔回收台账

读 `meta/foreshadowing.json`：

```json
[{"id": "母亲的怀表", "description": "第三章出现但没解释来历",
  "planted": 3, "plannedPayoff": 12, "paidOff": null}]
```

判定：已过 `plannedPayoff` 仍未回收 → 逾期；埋下 10 章以上且没有回收计划 → 悬空。
**长篇写到一半而台账是空的，本身就是一条 finding**——要么台账没在维护，要么结构上
确实没埋任何东西。

## 五、署名解析踩到的两个坑

两个都是测试写完不过才暴露的，也都是真实文本里会发生的：

**1. 否定式被读成署名。** `林砚没答话。` 中，2-4 字的名字捕获吞掉了"没"，剩下
"答"匹配成说话动词，凭空造出一个叫"林砚没"的角色。修法是在动词前加否定字符的
负向后顾 `(?<![没不未别莫])`。

**2. 署名跨段落串台。** 尾部署名模式里的 `\s*` 能跨换行，于是

```
母亲说："你回来了。"

林砚说："嗯。"
```

中"你回来了。"被判给了两行之外的林砚。修法是把间隔限制为同行空白 `[ \t]*`，
并规定先匹配到的署名（前置式，歧义更小）不被后置式覆盖。

## 六、Nova Agent 侧的对应修改

| 问题 | 修改 |
|------|------|
| 去 AI 味清单靠自查 | 标注哪些条目由 `manuscript_check` 自动查（9/11 条），剩下的"完美角色""潜台词"明确留给人读 |
| 伏笔"每 5 章审计"靠记忆 | 改为维护 `meta/foreshadowing.json`，逾期由工具算 |
| 用 `virality_score` 给小说章节打分、< 65 需优化 | 删除。传播度是社交媒体指标，拿它当文学章节的验收线会把写作推向标题党和情绪外露，与同一份提示词里的"去 AI 味"方向相反。ContentAnalyst 保留给对外宣传文案 |
| 交付物含"每章 ContentAnalyst 评分" | 改为 `manuscript_check` 裁定 |
| 对话占比 30% 无从核对 | 工具默认下限 20%，需要 30% 就传 `minDialogueRatio: 0.3` |
| Phase 7/8 编号重复 | 重排 |

## 七、边界

工具查的是**机械毛病**，不是文学质量。`clean` 意味着没有可检测的机器痕迹、对话量够、
感官有层次——不意味着这一章好看。以下都在工具能力之外，报告里也这么写：

- 开篇钩子是否抓人、章末悬念是否成立
- 情感转折是否被铺垫支撑
- 情节前后是否矛盾
- 角色行为是否符合此前的人格设定
- 对话是否有潜台词

另外：署名解析只在正文使用可识别署名格式时有效。纯文学写法常常不写"某某说"，
此时角色声音检查没有输入，工具会报"识别不到说话人"而不是假装通过。
